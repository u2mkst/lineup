# 축구방

11인제 축구 **라인업 짜기**와 **전술 애니메이션 짜기**를 한 곳에서 하는 웹앱.

**우리 팀 전용 구단 운영 앱**. 일정과 참석 투표, 경기 기록과 시즌 통계, 선수단, 게시판, 그리고 라인업·전술 애니메이션 보드를 한곳에서 씁니다.
팀원만 쓸 수 있어요: 이메일로 가입한 뒤 **합류코드**를 입력해야 모든 데이터가 보여요. 역할은 관리자 / 선수 두 가지예요.

## 화면

| 탭 | 내용 |
|---|---|
| 홈 | 다음 일정(바로 투표), 시즌 승률 스냅샷, 최근 경기, 공지 |
| 일정 | 월간 달력(매치·회식·연습·기타), 참석 투표와 마감, 참석률·투표율, 라인업과 댓글 |
| 기록 | 시즌별 팀 기록(경기당 득점·실점, 무실점, 다득점 쿼터…)과 개인 기록(득점왕, 도움왕, 최고수비수, POTM, 최다 출전…), 경기 목록 |
| 전술 | 팀 공유 전술 보기·"확인했어요"·댓글, 내 전술 편집 |
| 더보기 | 선수단(구성·평균 연령·시즌 기록), 게시판(공지 고정·댓글), 내 프로필, 구단 관리 |

- **관리자**: 일정 등록, 경기 기록 입력(쿼터별 점수·골·도움·POTM), 선수 관리(번호 교체·겸임 포지션·부상·출생연도), 합류코드 재발급, 팀원 권한·선수 연결·내보내기, 전술 서버 저장과 팀 공유
- **선수**: 참석 투표, 전술·기록 조회, 게시판, 팀 공유 전술 복사(내 기기에만 저장)

## 처음 쓰는 사람도 쉽게

한 화면에 질문 하나, 큰 버튼 하나, 위쪽에 진행 막대(토스식 단계 화면)로 안내해요.

- **관리자 첫 설정**: 구단 이름 → 선수 한 명씩(이름 → 번호 → 포지션, 번호 중복은 바로 알려줘요) → 첫 일정 → 팀원 초대 링크 → 홈 화면 설치. 구단 관리의 "마법사 열기"로 다시 열 수 있어요
- **팀원 합류**: 초대 링크 → 이메일·비밀번호(조건을 입력하며 확인) → 자동 합류 → "나는 누구인가요?"
- 초대·설정 링크의 코드는 이 기기에 기억돼서, 인증 메일을 확인하고 돌아와도 이어져요

## 전술 보드
- 포메이션, 선수 배정, 상대팀(선택), 장면(키프레임) 애니메이션, 곡선 이동 경로, 달리기·패스 화살표·구역
- 선택 도구(그룹 이동), 장면별 교체, 선수별 이동 타이밍, 공 소유, 세트피스 템플릿 6종
- 내보내기: PNG, GIF, 영상, 이미지 템플릿 3종, 카카오톡 공유(`VITE_KAKAO_JS_KEY`가 있을 때 카드)
- PWA: 홈 화면 설치, 오프라인 동작

서버 환경변수가 없으면 로그인 없이 이 기기에서만 쓰는 개인 전술 보드로 동작해요.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 단위 테스트 (vitest)
npm run build   # 타입체크 + 빌드 (dist/)
```

## Supabase 설정

1. 새 프로젝트에서 `supabase/migrations/*.sql`을 파일명 순서대로 SQL Editor로 실행 (테이블, RLS 정책, 기본 명단, 일정·기록, 구단·멤버)
2. `.env.local`에 `.env.example`처럼 URL과 publishable key 입력 (Vercel에는 같은 이름의 환경변수)
3. 첫 관리자: 마이그레이션이 만든 1회용 `team_secret.admin_code`로 설정 링크 `https://<사이트>/#/setup/<admin_code>`를 만들어 한 번 열기 → 이메일로 가입하면 코드 입력 없이 관리자가 되고 설정 마법사가 시작돼요. 관리자가 생기면 이 코드(링크)는 사라져요
4. 팀원 초대: 마법사 마지막 단계(또는 구단 관리)에서 초대 링크 `https://<사이트>/#/join/<합류코드>`를 단체방에 공유 — 누르고 가입하면 자동 합류 (재발급하면 이전 코드는 무효). 링크가 안 열리면 합류코드를 직접 입력할 수도 있어요
5. Auth 설정의 "Confirm email"을 끄면 가입 즉시 사용할 수 있어요 (켜 두면 인증 메일이 필요)

카카오톡 카드는 Kakao Developers에서 앱을 만들고 JavaScript 키를 `VITE_KAKAO_JS_KEY`로 넣은 뒤, 앱 설정 > 플랫폼 > Web에 사이트 주소를 등록해야 해요.

접근 제어는 전부 RLS가 맡아요. 모든 테이블은 멤버만 읽을 수 있고, 쓰기는 관리자(또는 본인 투표)만 가능해요. 브라우저에 들어가는 키는 publishable key뿐이에요.

React + Vite + TypeScript + zustand + supabase-js. 배포는 Vercel (Framework: Vite, 빌드 `npm run build`, 출력 `dist`).
