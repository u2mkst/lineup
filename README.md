# 축구방

11인제 축구 **라인업 짜기**와 **전술 애니메이션 짜기**를 한 곳에서 하는 웹앱.

- **라인업**: 포메이션 선택 → 선수 탭으로 배정 / 끌어서 위치 조정, 상대팀 라인업(선택), 교체 명단
- **전술**: 라인업이 장면 1. 장면을 이어 붙이며 선수·공을 옮기면 장면 사이를 부드럽게 재생
  - 달리기(점선)·패스(노란 선) 화살표, 구역 표시, 지우개, 장면 순서 변경
  - 되돌리기/다시 실행 (Ctrl+Z / Ctrl+Shift+Z), 스페이스바로 재생
- **내보내기**: 라인업 PNG, 장면 PNG, 전술 GIF, 전술 영상(mp4/webm), 이미지 템플릿 3종(다크/라이트/네이비). 모바일에서는 공유창으로 카카오톡 전송
- **링크 공유**: 전술 전체를 링크 하나로 공유 (서버 없이 URL에 담김)
- **PWA**: 홈 화면에 설치, 오프라인 동작
- **곡선 이동 경로**: 장면 사이 이동 경로 가운데 점을 끌면 선수·공이 곡선으로 움직여요
- **전술 편집 심화**
  - 선택 도구: 여러 명 선택(탭·영역·라인별 빠른 선택)해서 한꺼번에 이동
  - 장면별 선수 교체: 이동 도구로 선수를 탭하면 그 장면부터 다른 선수로 교체 (이후 장면에 이어짐)
  - 선수별 이동 타이밍: 출발·도착 시점을 선수마다 다르게
  - 공 소유: 공을 선수 가까이 놓으면 링이 표시되고 선수를 따라다녀요
  - 세트피스 템플릿 6종: 킥오프, 코너킥 공격·수비, 프리킥 공격·수비, 스로인
- **경기와 참석 투표** (서버 연동 시): 관리자가 경기를 등록하면 팀원이 로그인 없이 이름만 골라 참석·미정·불참을 투표해요. 경기 페이지에서 라인업을 보고 "확인했어요"와 댓글을 남길 수 있어요
- **선수 상태**: 겸임 포지션과 부상 표시. 자동 채우기는 부상 선수를 마지막 순위로 쓰고, 선수 선택 창에 참석 여부와 부상이 표시돼요
- **카카오톡 카드**: `VITE_KAKAO_JS_KEY`를 설정하면 라인업 이미지 카드와 경기 정보 카드를 카톡으로 보내요
- **서버 연동 (Supabase)**
  - 선수 명단은 서버가 기준이고 로그인 없이도 볼 수 있어요
  - 관리자(가입한 계정 전부): 선수 추가·삭제·수정, 등번호 변경과 맞교체, 전술 자동 서버 저장, "팀 공개" 전환
  - 팀원은 로그인 없이 "팀 공개" 전술을 보고 내 전술로 복사할 수 있어요
- 로그인하지 않으면 전술은 브라우저(localStorage)에 저장되고, 홈에서 JSON 백업/복원을 할 수 있어요.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 단위 테스트 (vitest)
npm run build   # 타입체크 + 빌드 (dist/)
```

## Supabase 설정

1. 새 프로젝트에서 `supabase/migrations/*.sql`을 파일명 순서대로 SQL Editor로 실행 (테이블, RLS 정책, 기본 명단, 경기·참석·댓글)
2. `.env.local`에 `.env.example`처럼 URL과 publishable key 입력 (Vercel에는 같은 이름의 환경변수)
3. Auth 설정의 "Confirm email"을 끄면 가입 즉시 사용할 수 있어요 (켜 두면 인증 메일이 필요)

카카오톡 카드는 Kakao Developers에서 앱을 만들고 JavaScript 키를 `VITE_KAKAO_JS_KEY`로 넣은 뒤, 앱 설정 > 플랫폼 > Web에 사이트 주소를 등록해야 해요.

환경변수가 없으면 서버 없이 이 기기에서만 동작해요. 접근 제어는 전부 RLS가 맡고, 브라우저에 들어가는 키는 publishable key뿐이에요.

React + Vite + TypeScript + zustand + supabase-js. 배포는 Vercel (Framework: Vite, 빌드 `npm run build`, 출력 `dist`).
